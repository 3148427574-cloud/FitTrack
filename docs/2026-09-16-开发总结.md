# FitTrack 开发总结（2026-09-16）

今晚完成的改动，按主题记录，方便下次继续。

## 本次完成

### 1. AI 辅助训练计划生成
- 新增 `AIService.swift`：调用 AI 生成每日训练计划，输入 = 训练历史（近 20 次）+ 身体数据趋势 + 动作库 + 目标，输出结构化 JSON 解析为 `PlannedWorkout`。
- 未配置 key 或调用失败时，自动回退到 `TrainingPlanner.generatePlan` 固定模板。
- 生成按钮改为异步，带 loading 状态与结果提示。

### 2. AI 聊天窗口
- 侧边栏新增「AI 助手」页：可咨询动作替换、动作规范、计划调整、饮食问题，AI 能看到用户真实训练/身体数据（`contextString`）。

### 3. API 从 Claude 切到 DeepSeek
- `AIService.swift` 改为 DeepSeek 的 OpenAI 兼容接口：`POST https://api.deepseek.com/chat/completions`，`Authorization: Bearer`，模型 `deepseek-chat`。
- 计划生成 `temperature=0.3` 保证 JSON 稳定。
- key 存 Keychain（UserDefaults 兜底），存储键 `deepseek-api-key`，不硬编码。

### 4. 聊天历史持久化 + 清除
- `AppStore` 新增 `@Published chatMessages`，单独存 `chat.json`；切换视图/重启不丢。
- 保留最近 40 条，超出自动裁剪；底部「清空」按钮带确认。

### 5. 提醒事项双向完成同步
- `PlannedWorkout` 新增 `reminderID` 关联 `EKReminder.calendarItemIdentifier`。
- App 内点「完成」→ 推送提醒 `isCompleted`；点「跳过」→ 删除提醒。
- 提醒 App 里点「完成」→ 监听 `EKEventStoreChanged` 自动拉回并标记完成；另有「刷新状态」按钮兜底。

### 6. 历史训练清空/逐条删除
- 「历史训练」区新增「清空全部」（一键）和每条「删除」（精准），均带二次确认。

### 7. 训练计划含重量 + 卡路里
- 新增 `CalorieEstimator`（`Engine.swift`）：自重动作识别、MET 估算、起始重量兜底。
- 计划卡片显示每个动作的具体重量（自重/公斤）和卡路里，底部汇总「预计消耗 N 千卡」。
- 无历史 1RM 的新动作不再显示「待定」，改用基于体重的保守起始重量。

## 当前完整功能

- 概览（今日计划、目标进度）、训练（生成计划/同步提醒/记录训练/导出 .ics）、饮食（目标/示例餐单/食物库）、身体（体重趋势图/录入）、导入导出（JSON/CSV）、AI 助手、设置。
- 提醒同步两条路：EventKit（签名后生效）+ `.ics` 日历导出。

## 技术要点

- **卡路里公式**：`MET × 体重(kg) × 时长(小时)`；复合动作 MET 6.0、孤立 4.5、自重 5.0；每组按 1.5 分钟。
- **双向同步机制**：`PlannedWorkout.reminderID` ↔ `EKReminder.calendarItemIdentifier`，App 侧用 `markCompleted/markDeleted` 推送，提醒侧用 `fetchStatus` + `EKEventStoreChanged` 监听拉取。
- **数据文件**：`~/Library/Application Support/FitTrack/fittrack.json`（主数据）+ `chat.json`（聊天历史）。
